Features

  • Download apps and games
  • Search for apps and games

System requirements

  • arm32, arm64, x86 or x86_64 based Windows device
  • OS build 10.0.15063.0 (1703) or higher — 10.0.15254.603 (1709) recommended
  • 512 MB RAM, 1 GB recommended
  • An internet connection
  • Microsoft App Installer installed
